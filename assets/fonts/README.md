# Bundled display fonts

These scalable fonts make cards readable on Linux, WSL and Windows without a
separate font download. Original font data is unmodified.

- **Bungee Regular** — bold display headings. Upstream: https://github.com/google/fonts/tree/main/ofl/bungee. See `OFL-Bungee.txt`.
- **Fredoka Variable** — rounded playful headings/body copy. Upstream: https://github.com/google/fonts/tree/main/ofl/fredoka. See `OFL-Fredoka.txt`.

Both are distributed under the SIL Open Font License 1.1. Keep both license files
with the fonts when distributing this application. The release builder includes
only these named fonts/licenses; it does not bundle user-uploaded fonts or media.
